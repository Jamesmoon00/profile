뚜벅뚜밤

위치 기반 서비스로, 앱과 서버를 나눠 개발하고 AWS에 직접 올려 운영 중입니다. 배포 자동화를 붙여 develop → main 흐름에서 손을 대지 않아도 배포가 끝나도록 만들었습니다.

  • 백엔드는 EC2 위 Docker 환경으로 구성하고, GitHub → CodeBuild → ECR → CodeDeploy로 이어지는 CI/CD 파이프라인을 만들어 운영에 적용했습니다.
  • 프론트엔드는 Expo(React Native + expo-web)로 만들고, 정적 번들을 같은 EC2의 nginx가 서빙하도록 구성했습니다.
  • 카카오·Mapbox API를 연동해 지도와 위치 데이터를 처리했습니다.
